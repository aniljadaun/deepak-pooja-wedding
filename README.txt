FREE GITHUB PAGES HOSTING
1. Sign in to github.com and open your deepak-pooja-wedding repository.
2. Choose Add file > Upload files, upload the new index.html and commit changes (replacing the old file).
3. In the repository (not account) choose Settings > Pages.
4. Under Build and deployment, Source = Deploy from a branch; Branch = main; folder = /(root); Save.
5. Wait a few minutes, then visit https://YOUR-USERNAME.github.io/deepak-pooja-wedding/
6. Leave the Custom domain field EMPTY. You do not need to purchase a domain.
